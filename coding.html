المرحلة 1 — HTML

هيكل الصفحة: الوسوم، الروابط، الصور، القوائم، الجداول، والنماذج.

01

مقدمة إلى HTML

وش هو HTML ووش وظيفته بأي صفحة ويب

اشرحلي المفهوم هنا

HTML هي لغة توصيف (مو برمجة) تُستخدم لبناء هيكل أي صفحة ويب. كل جزء بالصفحة (عنوان، فقرة، صورة...) تحدده باستخدام «وسوم» Tags. كل صفحة HTML تبدأ بنفس الشكل الأساسي:

<!DOCTYPE html>
<html>
  <head>
    <title>
صفحتي
    </title>
  </head>
  <body>
    <h1>
مرحباً
    </h1>
    <p>
هذه أول صفحة ويب لي.
    </p>
  </body>
</html>

كذا بتطلع بالمتصفح:

جرّب بنفسك

غيّر كلمة «مرحباً» لاسمك، وشوف الصفحة تتغير قدامك فوراً.

العناصر والوسوم الأساسية

كيف تبني هيكل الصفحة بالعناصر (Elements)

الروابط

كيف تربط صفحاتك ببعض أو بمواقع خارجية

اشرحلي المفهوم هنا

وسم <a> يصنع رابط، وخاصية href تحدد وجهته (صفحة بنفس الموقع أو رابط خارجي). خاصية target="_blank" تفتح الرابط بصفحة/تبويب جديد بدل ما تطلع من صفحتك الحالية.

من نحن
</a>

</a>

الصور

إضافة وتنسيق الصور بالصفحة

اشرحلي المفهوم هنا

وسم <img> يعرض صورة، وما يحتاج وسم إغلاق. خاصية src تحدد مسار الصورة، وخاصية alt نص بديل يظهر لو الصورة ما تحمّلت — ومهم جداً لذوي الإعاقة البصرية ومحركات البحث.

<img
  src="cat.jpg"
  alt="قطة بيضاء تجلس على أريكة"
  width="220">

الفورمات

04

صندوق العناصر (Box Model)

أساس أي تخطيط CSS — الحواف، الهوامش، والمسافات

اشرحلي المفهوم هنا

  border: 2px solid #333;

نظرة عامة — تطبيقات الجوال لتخصص HCI

هذا القسم معلومات عامة (مو دروس كود). يكفي تفهم الطرق واللغات ووش مطلوب منك الآن — عشان تربط اللي تعلمته بالمواقع بعالم التطبيقات.

١) كيف يُبنى تطبيق جوال؟ ثلاث طرق

مو كل تطبيق يُكتب بنفس الأسلوب. كطالب HCI يهمّك تعرف الفرق، حتى لو ما برمجت تطبيقاً بعد:

  • أصلي (Native): يُبنى بلغة المنصة نفسها — Swift لآيفون، وKotlin لأندرويد. أقوى أداء ووصول لمزايا الجهاز، بس غالباً تطبيقين منفصلين.
  • مشترك / عابر للمنصات (Cross-platform): كود واحد يطلع منه تطبيق للجوالين. أشهر مسارين: Flutter (لغة Dart) وReact Native (JavaScript / TypeScript). كثير شركات تختارهم لتوفير الوقت.
  • ويب داخل تطبيق / PWA: واجهة تُبنى بـ HTML و CSS و JavaScript (نفس أساس المواقع)، وتُغلَّف كتطبيق أو تُثبَّت من المتصفح. اللي تتعلمه في هذه المرحلة يفيدك مباشرة هنا.
أقل شيء تفهمه: الموقع ≠ التطبيق الأصلي، بس كثير تطبيقات اليوم واجهتها قريبة من الويب — عشان كذا HTML و CSS أساس ممتاز قبل أي مسار جوال.

٢) اللغات اللي تفيد تخصص التفاعل — وش تبدأ فيه؟

ما تحتاج تتعلّم كل اللغات دفعة واحدة. رتّبها حسب قربها من شغل HCI (واجهات + تجربة):

  • الآن (أساسي المسار): HTML و CSS — هيكل الواجهة وشكلها. هذا اللي تتمرّن عليه هنا.
  • بعدها بخطوة: JavaScript (وأحياناً TypeScript) — تفاعل الصفحة: أزرار، تحقق من النماذج، تحديث المحتوى بلا إعادة تحميل. مفيدة للويب وReact Native.
  • لو اخترت مسار جوال لاحقاً: Dart مع Flutter، أو Swift / Kotlin لو حابب أصلي لمنصة واحدة.
  • مو لغة برمجة بس مهمة: أداة تصميم مثل Figma — تصمّم الشاشات والتدفّق قبل الكود، وهذا قلب شغل UX/UI.
وش مطلوب منك في هذه المرحلة؟ تُكمل دروس HTML و CSS وتبني المشروع الصغير. قسم الجوال هنا للفهم فقط — مو مطلوب تبرمج تطبيقاً الآن.

٣) وش لازم أي طالب تفاعل إنسان وحاسوب يكون عنده؟

حزمة أساسية تخلّيك تتكلم مع المصممين والمبرمجين بنفس اللغة:

  • فهم المستخدم: مين يستخدم المنتج؟ وش هدفه؟ وين يتعثر؟ (مقابلات، ملاحظة، اختبارات بسيطة).
  • مبادئ الواجهة: وضوح، تغذية راجعة، تناسق، أخطاء مفهومة — زي اللي أخذته بأساسيات HCI.
  • أساسيات واجهة حقيقية: HTML و CSS على الأقل، ووعي بوجود JavaScript.
  • تصميم وتدفّق: Wireframes، نماذج أولية، وأنماط الجوال (إبهام، لمس، إشعارات، شاشات صغيرة).
  • إتاحة ووصولية (Accessibility): نص بديل للصور، تباين ألوان، حجم لمس مناسب — صحّة المنتج مو «زينة».
  • تفكير عبر المنصات: وش يختلف بين موقع ومتجر تطبيق؟ (تثبيت، صلاحيات، إيماءات، وضع عدم الاتصال).
الخلاصة: متخصص HCI مو لازم يكون أقوى مبرمج، بس لازم يفهم كيف تتحوّل الفكرة لواجهة على الويب والجوال — وأنت الآن تبني أول طبقة من هذا الفهم.

المشروع الختامي — ابنِ بطاقتك التعريفية

هنا تجمع كل اللي تعلمته بمرحلتي HTML و CSS: عناوين، فقرات، قوائم، أزرار، ألوان، وصندوق العناصر. عدّل الكود خطوة خطوة وشوف بطاقتك الشخصية تتشكل قدامك.

  1. غيّر «اكتب اسمك هنا» لاسمك الحقيقي.
  2. غيّر الحرف داخل الدائرة لأول حرف من اسمك.
  3. أضف هواية ثالثة للقائمة بوسم <li>.
  4. غيّر اللون الذهبي #b89454 بالكود للونك المفضل — جرّب #2b6cb0 أو crimson.
