/// خط 02 — ترميز HTML & CSS

مرحلتان: HTML أولاً، بعدها CSS

تقدمك بمسار الترميز

ما بدأت بعد — افتح أول درس وابدأ

المرحلة 1 — HTML

هيكل الصفحة: الوسوم، الروابط، الصور، القوائم، الجداول، والنماذج.

01

مقدمة إلى HTML

وش هو HTML ووش وظيفته بأي صفحة ويب

اشرحلي المفهوم هنا

HTML هي لغة توصيف (مو برمجة) تُستخدم لبناء هيكل أي صفحة ويب. كل جزء بالصفحة (عنوان، فقرة، صورة...) تحدده باستخدام «وسوم» Tags. كل صفحة HTML تبدأ بنفس الشكل الأساسي:

<!DOCTYPE html>
<html>
  <head>
    <title>صفحتي</title>
  </head>
  <body>
    <h1>مرحباً</h1>
    <p>هذه أول صفحة HTML لي.</p>
  </body>
</html>

02

العناصر والوسوم الأساسية

كيف تبني هيكل الصفحة بالعناصر (Elements)

اشرحلي المفهوم هنا

كل عنصر HTML له وسم فتح ووسم إغلاق يحيطان بالمحتوى، مثل <p>...</p>. أشهر العناصر: h1 إلى h6 للعناوين بأحجام مختلفة، p للفقرات، div لتقسيم المحتوى لصناديق.

<h1>عنوان رئيسي</h1>
<h2>عنوان فرعي</h2>
<p>فقرة عادية فيها <span>كلمة مميزة</span>.</p>
<div>صندوق يحتوي عناصر ثانية</div>

قراءة إضافية (W3Schools) ↗
03

الخصائص Attributes

class و id وكيف تعطى الوسم معلومات إضافية

اشرحلي المفهوم هنا

الخاصية Attribute معلومة تُكتب داخل وسم الفتح. class تجمع عناصر متشابهة للتنسيق لاحقاً، وid يعرّف عنصراً واحداً فقط في الصفحة.

<p class="note">ملاحظة عامة</p>
<p id="intro">مقدمة فريدة</p>

قراءة إضافية (W3Schools) ↗
04

الروابط

كيف تربط صفحاتك ببعض أو بمواقع خارجية

اشرحلي المفهوم هنا

وسم <a> يصنع رابط، وخاصية href تحدد وجهته (صفحة بنفس الموقع أو رابط خارجي). خاصية target="_blank" تفتح الرابط بصفحة/تبويب جديد بدل ما تطلع من صفحتك الحالية.

<a href="about.html">من نحن</a>
<a href="https://example.com" target="_blank">
  زوروا هذا الموقع (يفتح بصفحة جديدة)
</a>

قراءة إضافية (W3Schools) ↗
05

الصور

إضافة وتنسيق الصور بالصفحة

اشرحلي المفهوم هنا

وسم <img> يعرض صورة، وما يحتاج وسم إغلاق. خاصية src تحدد مسار الصورة، وخاصية alt نص بديل يظهر لو الصورة ما تحمّلت — ومهم جداً لذوي الإعاقة البصرية ومحركات البحث.

<img src="cat.jpg" alt="قطة بيضاء تجلس على أريكة" width="220">

06

القوائم

قوائم مرقّمة وغير مرقّمة

اشرحلي المفهوم هنا

وسم <ul> يصنع قائمة غير مرقّمة (نقاط)، ووسم <ol> يصنع قائمة مرقّمة (1، 2، 3...). داخل كل قائمة تحط عناصرها بوسم <li>.

<ul>
  <li>حليب</li>
  <li>خبز</li>
</ul>

<ol>
  <li>افتح الموقع</li>
  <li>سجّل حساب</li>
</ol>

07

الجداول

عرض بيانات في صفوف وأعمدة

اشرحلي المفهوم هنا

الجدول يتكوّن من <table>، وكل صف <tr>. رأس العمود <th> والخلية العادية <td>. مفيد لجداول الدرجات أو المقارنات.

<table>
  <tr>
    <th>الاسم</th>
    <th>الدرجة</th>
  </tr>
  <tr>
    <td>سارة</td>
    <td>95</td>
  </tr>
</table>

قراءة إضافية (W3Schools) ↗
08

الفورمات

بناء نماذج إدخال بيانات (زي فورم التسجيل)

اشرحلي المفهوم هنا

وسم <form> يجمّع حقول إدخال بيانات المستخدم، مثل فورم تسجيل الدخول اللي استخدمته بهذا الموقع. أهم عناصره: <input> لحقل الإدخال، <label> لتسمية توضيحية، و<button> لزر الإرسال.

<form>
  <label for="name">الاسم:</label>
  <input type="text" id="name">
  <button type="submit">إرسال</button>
</form>

المرحلة 2 — CSS

شكل الصفحة: الألوان، الخطوط، الصندوق، والترتيب.

أكمل قراءة شروحات مرحلة HTML أولاً عشان تنفتح دروس CSS.

01

مقدمة إلى CSS

كيف تنسّق شكل عناصر HTML اللي بنيتها

اشرحلي المفهوم هنا

لو HTML يبني الهيكل، فـ CSS تعطيه الشكل: الألوان، الخطوط، المسافات... تقدر تختار أي عنصر HTML (زي h1) وتحدد له خصائص شكل.

h1 {
  color: #2b6cb0;
  font-size: 28px;
  text-align: center;
}

02

المحددات Selectors

كيف تختار العنصر اللي تبي تغيّر شكله

اشرحلي المفهوم هنا

المحدّد يقول للمتصفح: طبّق هذا الشكل على مين؟ اسم الوسم يختار كل العناصر من نوعه، النقطة .class تختار المجموعة، والمربع #id يختار عنصراً واحداً.

p { color: #333; }
.note { color: #b89454; }
#intro { font-weight: bold; }

03

الألوان والخطوط

لون النص، الخلفية، ونوع الخط

اشرحلي المفهوم هنا

color للون النص، background للخلفية، وfont-family لنوع الخط. هذي أول خصائص تخلي الصفحة شكلها مرتب مو نص أسود على أبيض فقط.

body {
  font-family: Tahoma, sans-serif;
  color: #222;
  background: #f4f1ea;
}

04

صندوق العناصر (Box Model)

أساس أي تخطيط CSS — الحواف، الهوامش، والمسافات

اشرحلي المفهوم هنا

كل عنصر HTML هو عملياً صندوق يتكوّن من 4 طبقات حول بعض: المحتوى (Content) بالنص، ثم الحشوة (Padding) فراغ داخلي، ثم الحد (Border) الإطار، ثم الهامش (Margin) فراغ خارجي يفصله عن العناصر الثانية. فهم هذا الصندوق هو أساس أي تصميم CSS.

.box {
  width: 160px;
  padding: 16px;
  border: 2px solid #333;
  margin: 20px;
}

05

ترتيب العناصر (Flex)

صف العناصر جنب بعض بمسافات منتظمة

اشرحلي المفهوم هنا

display: flex يخلّي العناصر داخل الصندوق تصطف في صف (أو عمود). gap تحدّد المسافة بينها. هذا أساس أغلب تخطيطات المواقع الحديثة.

.row {
  display: flex;
  gap: 12px;
}
